🚀 CloudSage — AI-Powered Cloud Cost Optimizer :-
CloudSage is a serverless, AI-powered platform that monitors EC2 instances in real time and recommends cost-saving actions like stopping or resizing 
idle or oversized instances. It uses AWS EventBridge, Lambda, Momento Cache, CloudWatch, Bedrock (Mistral), DynamoDB, and a Next.js front-end.
